# Financial Intelligence Dashboard | L'Oréal, LVMH & Hermès

## Project Overview

An interactive financial analysis and benchmarking dashboard comparing the financial performance of three major French-listed companies: L'Oréal, LVMH and Hermès, covering 2022–2024.

The project demonstrates financial statement analysis, KPI calculation, data visualization and financial benchmarking using Python.

## Technologies Used

- Python
- Pandas
- Plotly
- Streamlit
- GitHub

## Key Features

- Interactive financial dashboard
- Three-company financial benchmarking
- Revenue and net profit analysis
- Revenue growth and net profit margin comparisons
- Return on Assets (ROA) and Return on Equity (ROE) calculations
- Dynamic year filters and financial charts
- Executive financial insights

## Financial Methodology

**Net Profit Margin:** Consolidated net profit / Revenue × 100

**Return on Assets:** Consolidated net profit / Average total assets × 100

**Return on Equity:** Profit attributable to shareholders / Average equity attributable to shareholders × 100

ROA and ROE require consecutive year-end balance-sheet figures. Ratios are not calculated where the required data is unavailable.

## Data Sources

Financial information was manually compiled from company annual financial reports:

- L'Oréal: https://www.loreal-finance.com/
- LVMH: https://www.lvmh.com/
- Hermès: https://finance.hermes.com/

## Project Limitations

The companies operate in different business segments, and direct financial comparisons require care. Some historical balance-sheet data is incomplete, and all transcribed figures and calculated ratios should be reconciled against the official financial statements before investment use.
